## 🛍️ Power BI Student Survey Project – Retail Store Analysis ##
## 📘 Project Overview ##

This project analyzes the spending habits of students across various retail stores in the United States. Using a student survey dataset, it explores different purchase categories such as Video Games, Indoor Games, Toys, Books, and Gadgets.The main goal is to extract meaningful insights and design interactive Power BI dashboards that help understand retail spending patterns among students.

## 🏢 Industry Type

Retail Store

## 📊 Dataset

Source: Student Survey Dataset

# Key Columns:

Store Location

Store Setting

Total Amount of Purchase (TAP)

Age Groups

Product Categories (Video Games, Outdoor Sports, Indoor Sports, etc.)

## ❓ Problem Statement

To build a Power BI report that provides actionable insights into student spending behavior across different store locations and product categories.

## 🎯 Key Objectives
# 1. Tabular Visualization

Format Total Amount of Purchase (TAP) based on Store Location and Store Setting:

TAP between 0–35,000 → 🔴 Red

TAP between 35,000–60,000 → 🟡 Yellow

TAP above 60,000 → 🔵 Blue

# 2. Matrix Visualization

Display Outdoor Sports spending across Age Groups and Store Settings with color formatting.

# 3. Funnel Chart

Visualize Total Amount of Purchase by Store Setting with percentage labels relative to the first stage.

# 4. Pie Chart

Show Total Amount of Purchase by Store Location for Suburban stores only.

# 5. Scatter Plot

Plot Video Games vs Outdoor Sports spending across Age Groups.

Create a SandDance Plot comparing Indoor Sports vs Video Games across Age Groups for 3D exploration.

# 6. Row-Level Security (RLS)

Restrict access: e.g., Mani can view only Rural data.

# 7. Master Dashboard & Scheduled Refresh

Publish the report on Power BI Cloud Service.

Schedule data refresh every 4 hours (6 times per day).

# 8. Power BI Q&A

Display average student age using natural language queries.

Create a Donut Chart for Total Purchase by Store Location.

## ⚙️ Power BI Features Used

Conditional Formatting in Tabular Visualization

Matrix Visualization with Color Coding

Funnel, Pie, and Scatter Charts

SandDance Plot (3D Visualization)

Row-Level Security (RLS)

Scheduled Data Refresh

Power BI Q&A for Natural Language Queries

Delivered an interactive and insightful Power BI dashboard showcasing student spending trends across retail stores.
